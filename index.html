    How the fallback chain works
    1. https://lh3.googleusercontent.com/d/<ID>=w<width> — Google’s image CDN. Fastest and cookie-free, but only works if the file is shared Anyone with the link.
    2. https://drive.google.com/thumbnail?id=<ID>&sz=w<width> — the thumbnail endpoint. Usually survives when the direct CDN link is blocked.
    3. https://lh3.googleusercontent.com/d/<ID> — the same CDN with no size hint, so you get the original upload.
    4. https://lh3.google.com/u/0/d/<ID> — the Drive web host, which is stricter about referrers.
    5. https://drive.google.com/uc?export=view&id=<ID> — the classic form. This has been unreliable since 2024 because of third-party cookie changes, so it is tried last.

    The card tries these in order and uses the first one that actually paints. A photo only counts as loaded when the browser reports a decoded image, so a login page served with a 200 does not fool it.
